# android/ — Capacitor Android project

This folder contains the **hand-authored customizations** (package name,
icons, splash theme, permissions, Firebase Gradle wiring) for the Android
build. It is intentionally missing the Gradle wrapper binaries
(`gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`) and a couple
of auto-generated files (`capacitor.build.gradle`, `capacitor.settings.gradle`,
`app/src/main/assets/capacitor.config.json`) — those are machine-generated by
the Capacitor CLI and don't need to be hand-written or committed as
static text.

To finish the project, from the repo root run:

```
npm install
npx cap add android      # fills in the wrapper + generated Capacitor files
npx cap sync android      # copies src/ into app/src/main/assets/public
```

Then open in Android Studio (`npx cap open android`) or build from the CLI
(`./gradlew assembleRelease` / `bundleRelease`).

See the root `README.md` for the full Firebase + Play Store setup steps.
